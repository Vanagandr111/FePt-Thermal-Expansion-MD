# Pt–Pt и Pt–Fe: тепловое расширение на двух потенциалах

Дата: 2026-11-03. Орторомбический бокс 3×4×4 (192 атома),
0 / 300 / 1200 K, предварительная релаксация 500 шагов + рабочий участок
1500 шагов, шаг 1 фс, баростат Берендсена (изотропный), термостат Ланжевена.
Фактические средние температуры на рабочем участке: 301.8 K и 1209.6 K.

## Проверки

* Инвариант a(0 K) < a(300 K) < a(1200 K) выполнен во всех четырёх сериях.
* Давление на рабочем участке: |⟨P⟩| ≤ 917 бар при допуске 1500 бар.
* Влияние размера бокса: 192 атома (бокс 11.77 Å) и 256 атомов (15.70 Å)
  дают a = 3.9419 и 3.9418 Å при 300 K — разница 0.0001 Å, размер не влияет.
* r2SCAN точнее: +0.44 % против +1.71 % на платине. MP-0 (PBE) систематически
  завышает период ГЦК-металлов, это свойство потенциала, а не расчёта.
* Статика 0 K: релаксация позиций (BFGS, fmax 0.02 эВ/Å), затем бисекция по
  P(a) до |P| < 100 бар. Остаточное давление ±1.7 кбар — следствие
  стохастической конфигурации сплава (каждый запуск даёт новое распределение
  Fe/Pt по узлам), поэтому a(0 K) для Pt–Fe имеет разброс порядка 0.01 Å.
