Статусы: ok — все зависимости на месте,
      ошибок не было; warn — что-то не установлено или не найдено
      (модель, интерпретатор), расчёт может не стартовать;
      error — последний расчёт завершился с ошибкой или базовая
      зависимость отсутствует; update — на GitHub вышла более
      свежая версия — нажмите «Обновить». Клик по бейджу открывает эту
      вкладку.

    
Как работает

    

      • Расчёт: ASE-MD (NPT: Langevin-термостат + MTK-баростат,
      1 fs/шаг) с нейронным потенциалом MACE на GPU (fp16/bf16/fp32)
      или CPU; модели скачиваются on-demand из каталога ACEsuit и лежат
      в potentials/gpu/. torch.compile по умолчанию выключен в GUI
      (на части ПК антивирус резал ptxas с WinError 5); на машинах, где
      он работает, включается переменной окружения
      FEPT_COMPILE=1 — тогда движок сам проверит компилятор
      до старта и при блоке всё равно продолжит без него.

      • MCP (для ИИ-агентов): сервер JSON-RPC на
      http://127.0.0.1:8321 (клиент fept_gui) — инструменты
      gui_set_form, gui_start_run, gui_status, gui_get_form,
      gui_calibrate, gui_list_potentials, gui_download_model и др.;
      переменная FEPT_GUI_URL перенаправляет адрес.

      • CLI: движком управляется и напрямую —
      python scripts/run_main_mace.py --help и
      python scripts/run_main.py --help (LAMMPS-режим);
      все прогоны пишут CSV/XLSX/графики/md_*.log в results_*/.

      • Тесты: python -m pytest -q (~30 с, без сети и GPU).
